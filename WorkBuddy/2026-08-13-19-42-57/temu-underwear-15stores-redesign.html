ChatGPT 直用版 · 15 个店铺 × 6 张主图 = 90 条可复制指令 · 每条指令包含具体色值、角度、构图、文字与色调参数

90 条指令 复制 → 粘贴 → 出图 每店视觉完全独立 规避 AI 比价限流

零、3 步用法（先读这个）

你把任意一张内裤原图发给 ChatGPT，再复制对应店铺对应主图的指令贴给它，它就能按指令改出一张与其他店铺完全不同的图。

STEP 1

选原图

从你手头的内裤原图（平铺图 / 挂拍图 / 模特图 / 细节图，男款或女款皆可）里挑一张上传给 ChatGPT。每条指令标注「基于原图」作为建议，可混用。

STEP 2

复制指令

找到对应店铺（店1~店15）的对应主图（主图1~主图6），点指令右上角的「复制」，整段贴到 ChatGPT 对话框。

STEP 3

微调出图

ChatGPT 出图后不满意，追加一句即可：内裤再放大一点、背景换成米色、去掉文字。每店固定用同一套指令，不要跨店混用。

STEP 4

同步改文案

每店底部有一段「SKU + 标题关键词」参考，改图时把店铺链接里的 SKU 和标题也一并换掉，图+文+编码三层不同，平台才无法关联。

⚠️ 用前必看 3 条红线

  • 同一张原图在 15 个店必须「水平翻转 + 裁切比例 + 调色」三样至少做两样，直接发原图 = 白改
  • 内裤核心卖点词 15 店不能重复：Breathable / SoftTouch / Comfort / CottonSoft / Airy / Premium / ComfortFit / Everyday / Natural / UltraSoft / FeelFresh / DailyComfort / StretchFit / Classic / FunFit（按店分配）
  • 每条指令里的 色值 / 角度 / 文字 参数别乱换，那是每店独有的视觉指纹

二、执行顺序与自查清单

⚠️ 改图时最容易犯的 3 个错误

  • 只改背景不改角度：换了底色但内裤还是原来的平铺正面照，AI 仍能通过轮廓特征关联。每条指令里的「角度/裁切/翻转」必须同步执行。
  • 15 店用同一句文案：别图省事每店都写 "Breathable"。手册已给每店分配专属卖点词（Breathable / SoftTouch / Comfort / CottonSoft / Airy / Premium / ComfortFit / Everyday / Natural / UltraSoft / FeelFresh / DailyComfort / StretchFit / Classic / FunFit），文案、SKU、标题三处必须一致且不同店。
  • 原图直接复用：从原图裁剪的局部也必须二次处理（翻转/调色/加颗粒），否则局部特征仍会被识别。

每周执行清单（按店推进）

  1. 按店1→店15顺序，每店先改 主图1（主视觉），上传到店铺；观察 3 天流量/曝光变化
  2. 主图1 稳定后，补齐主图2（面料细节）和主图3（场景图）
  3. 每改一店，同步更新该店 SKU 编码 + 标题关键词 + 卖点描述（见每店底部参考）
