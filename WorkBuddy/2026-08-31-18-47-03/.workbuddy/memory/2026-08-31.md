## 微信公众号长图文章抓取工作流（新增 SOP）
- 用户给微信文章 `mp.weixin.qq.com/s/...`，WebFetch 只能拿到标题与署名，正文数据全在长图里。
- 解决：curl + Referer 下载 `mmbiz.qpic.cn` 下的 `?wx_fmt=jpeg|png` 图片，按出现顺序命名，再用 Read 工具多模态读图 OCR 数字。
- 关键 grep：`grep -Eo 'data-src="https://mmbiz\.qpic\.cn/[^"]*640\?wx_fmt=(jpeg|png)"'`
- 注意：BSD grep（macOS 默认）要用 `-E` 才支持 `\|`；循环里 BSD `sed` 拆 URL 时 `sed 's/data-src="//; s/"$//'` 即可。
- 完整命令（直接复用）：
  ```bash
  curl -sS -m 30 -A "Mozilla/5.0 ..." -e "https://mp.weixin.qq.com/" URL -o szu.html
  grep -Eo 'data-src="https://mmbiz\.qpic\.cn/[^"]*640\?wx_fmt=(jpeg|png)"' szu.html \
    | sed 's/data-src="//; s/"$//' > list.txt
  i=0; while read -r u; do i=$((i+1)); n=$(printf "%02d" $i); \
    curl -sS -m 40 -A "Mozilla/5.0 ..." -e "https://mp.weixin.qq.com/" "$u" -o "p$n.jpg"; \
    done < list.txt
  ```
- 然后 `Read` 每张图，多模态 OCR。注意 1M+ 大图会自动缩放，可直接读。
