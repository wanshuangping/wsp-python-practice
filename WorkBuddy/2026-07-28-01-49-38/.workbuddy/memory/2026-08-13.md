2. 通过 `lsof` / `networksetup` / `curl` 检查确认 TUN 已生效，流量被正确代理。

4. 测试出口 IP：最初为 `104.234.0.177`（WAP.AC 洛杉矶机房），被 OpenAI 风控。
5. 通过 Clash API（`/tmp/verge/verge-mihomo.sock`）将 GLOBAL / 节点选择 / ChatGPT 组切换至 `🇯🇵日本4-IEPL-家宽`。
6. 切换后出口 IP 变为 `121.101.96.182`（Sony Network Communications 日本家宽）。
7. `chatgpt.com` 返回 `cf-mitigated: challenge`（Cloudflare 验证码挑战），不再是地区限制 403，说明 IP 已可用。
