# 2026-08-14 工作记录

## 关闭本机 Clash（解决国内图片打不开）

用户开代理后国内图片/服务加载异常，要求关闭 Clash。

### 操作
1. 检查状态：系统代理已关（之前），但 TUN 模式仍活跃（utun0-5 在，出口 IP 仍走日本节点）。
2. `osascript -e 'quit app "Clash Verge Rev"'` 发退出指令，但 GUI 进程未退干净（zsh 下 `kill` 变量未按空格拆分，且部分进程为 root 级无法 kill）。
3. 通过 Clash 核心 unix socket 关闭 TUN：
   `curl -X PATCH --unix-socket /tmp/verge/verge-mihomo.sock http://localhost/configs -d '{"tun":{"enable":false}}'`
4. 验证：baidu.com 返回 200，无 53 端口 DNS 劫持、无 198.18 路由 → 国内流量恢复直连。

### 残留
- root 级 `clash-verge-service`（PID 37140）仍运行并挂着 utun 网卡，但不再拦截流量，无害。彻底清理需 sudo pkill 或重新打开 App 正常退出。
