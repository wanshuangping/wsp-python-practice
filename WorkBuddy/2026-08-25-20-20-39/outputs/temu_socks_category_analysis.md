## 二、运动功能袜：产品特征 + 标题埋词

### 2.1 滑雪袜 Ski Socks（男/女/男童/女童）

**产品特征**
- **功能**：保暖、吸湿排汗、小腿/胫骨缓冲垫、足弓支撑、无缝减少摩擦
- **材质**：美利奴羊毛（Merino Wool）混纺、腈纶/尼龙/氨纶、加厚毛圈
- **高度**：中筒-高筒（覆盖小腿肚以上），适配雪靴
- **设计细节**：分区加厚（脚跟、脚趾、胫骨）、压缩织法、防滑罗口
- **儿童款**：尺码范围明确（如 Kids 4-7 / Youth 8-12）、卡通配色、易穿脱

**标题埋词**
- 核心词：Merino Wool Ski Socks / Thermal Ski Socks / Snowboard Socks
- 属性词：Warm, Thick, Cushioned, Moisture-Wicking, Breathable, Over-the-Calf
- 场景词：Skiing, Snowboarding, Winter Sports, Cold Weather, Outdoor
- 人群词：Men / Women / Boys / Girls / Kids / Youth
- 营销词：2 Pack, 3 Pack, Anti-Odor, Seamless Toe, Arch Support

**示例标题**
> Merino Wool Ski Socks for Men Women Kids Thick Warm Thermal Snowboarding Socks Over the Calf Cushioned Winter Sport Socks 3 Pairs

---

### 2.2 足球袜 Soccer/Football Socks（男/女）

**产品特征**
- **功能**：小腿保护、防滑防脱、吸汗速干、足弓支撑
- **材质**：聚酯纤维/尼龙/氨纶混纺，轻量透气
- **高度**：长筒及膝（Knee High），适配护腿板（Shin Guards）
- **设计细节**：袜口收紧不下滑、脚底加厚防滑、足弓弹性带、多色可选（球队色）
- **儿童/青少年款**：分龄尺码、护腿板固定槽

**标题埋词**
- 核心词：Soccer Socks / Football Socks / Knee High Athletic Socks
- 属性词：Long Tube, Shin Guard, Non-Slip, Cushioned, Breathable, Quick-Dry
- 场景词：Football, Soccer, Sports Training, Team Sports, Match
- 人群词：Men / Women / Boys / Girls / Kids / Youth
- 营销词：Team Pack, Multi-Color, 4 Pack, Compression Fit

**示例标题**
> Knee High Soccer Socks for Men Women Youth Non Slip Football Socks Long Tube Shin Guard Holders Breathable Athletic Sport Socks 4 Pairs

## 三、压缩/紧身袜：产品特征 + 标题埋词

### 3.1 足球压缩袜 / 紧身袜 Soccer Compression Socks/Leg Sleeves

**产品特征**
- **功能**：梯度压缩促进血液循环、减少肌肉疲劳、固定小腿肌肉、辅助护腿板
- **压力等级**：15-20 mmHg（运动级）最常见
- **材质**：尼龙/氨纶高弹面料
- **款式**：连脚压缩袜（Compression Socks）或 袜套/腿套（Calf Sleeves）
- **设计细节**：分段压力、防滑上口、透气网眼、UV 防晒

**标题埋词**
- 核心词：Compression Socks / Compression Calf Sleeves / Soccer Leg Sleeves
- 属性词：15-20 mmHg, Graduated Compression, Shin Guard Sleeves, Calf Support
- 场景词：Running, Soccer, Football, Travel, Recovery, Nurses
- 人群词：Men / Women / Athletes
- 营销词：2 Pack, Medical Grade, Performance, Circulation

---

### 3.2 跑步压缩袜 / 紧身袜 Running Compression Socks/Tights

**产品特征**
- **功能**：延缓肌肉酸痛、稳定关节、加速恢复、提升运动表现
- **压力等级**：15-20 mmHg / 20-30 mmHg
- **材质**：尼龙/氨纶/聚酯，四向拉伸
- **款式**：过膝压缩袜、小腿套、压缩裤袜
- **设计细节**：足跟加厚、脚趾无缝、防滑束口、夜跑反光

**标题埋词**
- 核心词：Compression Running Socks / Running Compression Sleeves / Athletic Compression Tights
- 属性词：Graduated Compression, 20-30 mmHg, Calf Support, Recovery, Breathable
- 场景词：Running, Marathon, Trail Running, Travel, Pregnancy, Nursing
- 人群词：Men / Women
- 营销词：Medical Compression, Performance, Recovery, 2 Pairs

---

### 3.3 健身压缩袜 / 紧身袜 Fitness Compression Socks/Tights

**产品特征**

## 六、TEMU 标题撰写通用公式

### 6.1 推荐结构

```
[核心词] + [材质/功能属性] + [场景/人群] + [款式细节] + [包装/营销词]
```

**示例拆解**
> Merino Wool Ski Socks | Thick Warm Thermal | Men Women Kids | Over the Calf Cushioned | 3 Pairs

### 6.2 关键词优先级

| 优先级 | 词类型 | 说明 |
|--------|--------|------|
| P0 | 核心品类词 | Ski Socks / Yoga Socks / Compression Socks / Pantyhose |
| P1 | 功能/材质词 | Merino Wool, Non-Slip, Compression, Thermal, Fleece Lined |
| P2 | 人群/场景词 | Men Women, Pregnant, Running, Winter |
| P3 | 款式/数量词 | Knee High, No Show, 3 Pairs, Over Bump |
| P4 | 营销词 | Soft, Comfortable, Gift, Anti-Odor |

### 6.3 避坑提醒

1. **不要堆砌同义词**：TEMU 算法对重复词降权，如同时写 Socks / Hosiery / Stockings 要区分场景
2. **尺码表达**：欧美用 S/M/L 或 Shoe Size 6-10，避免纯亚洲尺码
3. **压力袜必须标 mmHg**：15-20 / 20-30 / 30-40 是买家决策点
4. **儿童款必须标年龄/鞋码**：Kids 4-7 / Youth 8-12 / Toddler
5. **孕妇款避免"紧身"负面联想**：用 Support / Over Bump / Soft 替代 tight
6. **滑雪袜强调 Over-the-Calf**：高筒是雪靴刚需
7. **足球袜强调 Shin Guard / Knee High**：与护腿板强相关
