## 一、为什么对比图能帮你"解绑同款"

TEMU 比价系统会把外观/功能相似的产品绑在一起压价。你的产品是 **超宽口 + 非束缚罗口 + 适合肿胀脚**，但图2只展示了"黑色中筒袜"，系统会把它识别成普通运动袜，然后跟海量 9.9 美金跑量款比价。

对比图的作用：

1. **让审核/算法看到功能差异**：这不是普通袜，是 Diabetic / Non-Binding / Extra Wide 功能袜
2. **让买家看到价值差异**：普通袜会勒脚，这款不会
3. **脱离普通袜比价池**，进入护理袜/功能袜池，核价更有空间

## 三、方案 B：痛点对比图（直击购买动机）

### 构图

- 上半部分：穿普通袜一天后的小腿，有明显的红色勒痕
- 下半部分：穿本产品一天后的小腿，无勒痕
- 可以用同一双腿做"Before / After"对比

### 文案

**英文**：

- BEFORE：Tight Elastic Leaves Painful Marks
- AFTER：Non-Binding Top Stays Comfortable All Day
- Text：Extra Wide Socks for Swollen Feet

**中文**：

- 以前：紧口袜留下疼痛勒痕
- 现在：非束缚罗口全天舒适
- 标题：超宽口袜 · 专为肿胀脚设计

### 制作建议

- 如果你没有 Before 实拍图，可以用 AI 生成"勒痕腿"素材
- 你的原产品图作为 After 效果图使用

## 五、方案 D：功能差异化解绑同款策略（结合你的微信截图）

### 核心打法

不要在标题里只写 "Black Crew Socks"，而是把功能词放到核心位置：

| 普通袜标题                          | 你的差异化标题                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Men's Cotton Crew Socks 6 Pack | Extra Wide Diabetic Socks for Swollen Feet Non Binding Loose Top 3 Pairs      |
| Athletic Running Socks         | Extra Wide Recovery Socks for Edema Non Binding Circulation Support Socks     |
| Black Crew Socks Women         | Non Binding Extra Wide Socks for Pregnant Women Swollen Feet Diabetic 3 Pairs |

**目的**：算法抓取标题关键词时，会把你的产品分到 `diabetic socks`、`wide socks`、`non-binding socks` 池子，而不是 `athletic socks` 跑量池。

## 六、只有 1 张图怎么落地？制作步骤

### 方法 1：AI 生成完整对比图（最快）

1. 把你的产品图和 Prompt 一起丢给 ChatGPT / Midjourney / 可灵 / 极睿电商生图
2. 生成左右对比图
3. 用 Canva / 美图设计室加文字标注

### 方法 2：抠图 + 合成（更可控）

1. 用 remove.bg 把你原产品图的袜子抠出来
2. 找/生成一张"普通袜勒腿"的素材图
3. 在 Figma / Canva / PS 里左右拼接
4. 加文字标注和箭头

### 方法 3：直接找素材网站买图（最稳）

- 在 Shutterstock / iStock / Adobe Stock 搜 "diabetic socks comparison" / "tight sock marks"
- 买下后把你的产品图替换进去
- 注意：不要用竞争对手带水印的图

## 七、避坑清单

| ❌ 不要做                                        | ✅ 应该做                                                      |
| -------------------------------------------- | ---------------------------------------------------------- |
| 直接盗用图1/图2的品牌图（侵权）                            | 学习构图和文案逻辑，用自己的产品图重拍/合成                                     |
| 在图中写 "cure diabetes" / "treat diabetic foot" | 用 "diabetic-friendly" / "for swollen feet" / "non-binding" |
| 左右两侧都用完全一样的袜子                                | 右侧普通袜颜色/款式明显区分，避免混淆                                        |
| 文字密密麻麻像牛皮癣                                   | 每侧 3-4 个卖点，用图标+短句，清晰高级                                     |
| 只做中文图                                        | 主图必须用英文（欧美站点）                                              |
