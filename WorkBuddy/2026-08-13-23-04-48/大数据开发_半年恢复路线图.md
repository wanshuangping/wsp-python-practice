# 大数据开发工程师 · 半年能力恢复路线图

> 适用对象：专业为「大数据技术与应用」、当前代码水平较基础、希望用约 6 个月（每周 10–20 小时）恢复能力并重新进入程序员岗位。
> 技术栈主线：**Python 起步 → SQL/数据库 → Linux/采集 → Spark 生态 → 实时/调度/数仓 → 综合项目+求职**。
> 默认节奏：每周约 3 小时理论跟课 + 5 小时编码练习 + 2 小时复盘笔记（共 10h 起，可上探到 20h）。

---

## 0. 开始之前：先做能力基线自检

不要跳过这步。用 1–2 小时诚实地答一遍，决定你能否"压缩"某些月份：

- [ ] 能否不用搜索，写出一个 Python 函数（含参数、返回值、循环、判断）？
- [ ] 能否解释 列表 / 字典 / 集合 的区别与适用场景？
- [ ] 是否知道 `git add / commit / push` 基本流程？
- [ ] 是否能在终端（命令行）新建、进入、列出目录？
- [ ] 是否写过哪怕一条 `SELECT ... JOIN ... GROUP BY`？

> 如果上面大部分打叉 → 按计划从 Month 1 老老实实走；如果 Python 基础还在、只是"手生" → Month 1 可压到 2–3 周，把时间挪给 Month 4–5。

## 1. 六个月总览

| 月份 | 主题 | 核心产出 |
|------|------|----------|
| M1 | Python 基础恢复 | 能独立写 100–200 行脚本，10 个小练习 |

## 2. 分月计划

### Month 1 — Python 基础恢复（找回手感）

**目标**：把"写代码"从陌生变成本能反应。

- **第 1–2 周**：语法重修
  - 变量、类型、运算符、字符串格式化
  - 流程控制：if / for / while
  - 容器：list / tuple / dict / set 与常用方法
  - 函数：定义、参数、返回值、作用域
- **第 3–4 周**：实战小练习（每个独立成文件，跑通为止）
  1. 命令行计算器
  2. 待办清单（增删改查，存文件）
  3. 词频统计（读文本 → 统计词出现次数）
  4. 猜数字游戏
  5. 批量重命名脚本
  6. 简单日志解析（提取时间/IP/关键字）
  7. 斐波那契 / 质数判断
  8. 读写 CSV（用标准库 csv）
  9. 用 `requests` 抓一个静态网页标题
  10. 把前 9 个练习封装成带 `main()` 的模块

**月末自检**：不查资料，30 分钟内写出一个"读 CSV → 按某列分组求和 → 写回新文件"的脚本。做不到就延长一周，不要急着进 M2。

---

### Month 2 — Python 进阶 + SQL 基础

**目标**：从"能写"到"写得像样"，同时补上数据岗吃饭的家伙 SQL。

- **Python 进阶**
  - 面向对象：class / 属性 / 方法 / 继承
  - 常用标准库：`os` `re` `datetime` `json` `pathlib`
  - 进阶语法：列表推导、生成器、装饰器（理解即可）
  - 异常处理：`try/except` 写健壮脚本
  - 虚拟环境：`venv` + `pip` + `requirements.txt`
- **SQL 基础**（SQLite 起步，再上 MySQL）
  - `SELECT / WHERE / ORDER BY / LIMIT`
  - 聚合：`GROUP BY` + `COUNT/SUM/AVG`
  - 多表：`INNER/LEFT JOIN`
  - **窗口函数**：`ROW_NUMBER / RANK / SUM() OVER` —— 面试高频
  - 子查询与 CTE（`WITH`）
- **小项目**：用 Python + SQLite 做一个"个人记账本"——命令行增删查，支持按月统计、分类汇总（练 SQL + 面向对象 + 文件持久化）。

**月末自检**：能手写一条带窗口函数的查询，并讲清它和 `GROUP BY` 的区别。

---

### Month 3 — Linux + 数据采集 + 数据库

**目标**：具备"工程环境"的基本生存能力（这是大数据岗的硬门槛）。

- **Linux 必会**（每天开终端练）
  - 文件：`ls / cd / pwd / cp / mv / rm / mkdir / touch`
  - 查看：`cat / head / tail / grep / less`
  - 权限：`chmod / chown` 概念
  - 进程/网络：`ps / top / netstat` 看个大概
  - 管道与重定向：`|` `>` `>>` `xargs`
  - 包管理：`apt` 或 `brew` 基础
- **Git（必须熟练）**：init / add / commit / branch / checkout / merge / push / pull；在 GitHub 建一个仓库放你的练习
- **数据库**：
  - MySQL 安装 + 建库建表 + 索引概念
  - Redis 初识：是什么、能解决什么（缓存/计数），跑通 set/get
- **采集入门**：`requests` + `BeautifulSoup` / `json` 解析；理解 API 与 HTML 两种数据源
- **项目**：一个**定时采集管道**——每天定时（cron 或 Python `schedule`）抓某公开数据 → 清洗 → 入库 MySQL。这是你简历上第一个"管道"雏形。

**月末自检**：能在 Linux 终端从零建库、建表、导入一份 CSV，并用 SQL 查出结果；Git 提交历史干净可读。

---

### Month 4 — 大数据核心（Hadoop / Spark）

**目标**：摸到真正的大数据引擎，完成从"脚本"到"分布式处理"的认知升级。

- **Hadoop 概念（先懂原理，不急着搭集群）**
  - HDFS：分块、副本、NameNode/DataNode
  - MapReduce：思想 > 代码（理解 shuffle/排序）
  - YARN：资源调度是什么
- **Spark（重点，用 PySpark）**
  - 本地用 Docker 或单机模式跑起来
  - RDD： transformation / action、惰性求值
  - DataFrame & Spark SQL：和 Pandas 像但分布式的
  - 读写：CSV / Parquet / JDBC 到 MySQL
  - 调优常识：分区、cache、shuffle 概念
- **项目**：用 PySpark 重写 M3 的采集数据，做"清洗（去重/补空/类型转换）+ 多维度聚合"，输出到 Parquet 并对比与 Pandas 写法的差异。

**月末自检**：能说出 RDD 和 DataFrame 的区别；能本地提交一个 PySpark 作业并拿到正确聚合结果。

---

### Month 5 — 实时/调度/数仓

**目标**：把零散技能串成"生产级管道"，补齐岗位最常见的三块。

- **调度**：Airflow 基础——DAG 概念、Operator、`cron` 表达式；把你 M3/M4 的脚本编排成一个有依赖的 ETL 流
- **消息队列**：Kafka 概念——topic / producer / consumer；用 `kafka-python` 写个最小收发 demo
- **流处理**：Flink 或 Structured Streaming 入门，理解"批 vs 流"的差异（概念为主，能跑通一个单词计数即可）
- **数据仓库**：分层思想 ODS / DWD / DWS / ADS；维度表与事实表；为何要分层
- **工程化**：`pytest` 写单元测试；项目写 `README`；用 Git 分支管理功能
- **项目**：一个**含调度的离线 ETL 管道**——MySQL(ODS) → Spark 清洗(DWD/DWS) → 结果表(ADS)，由 Airflow 每天定时跑，README 写清架构与重跑方式。

**月末自检**：别人照你 README 能本地把项目跑起来；你能解释每一层在做什么、为何分层。

---

### Month 6 — 综合项目 + 求职准备

**目标**：把半年所学收敛成一个"能讲 30 分钟"的端到端项目，并进入投递。

- **综合项目（简历核心）**：端到端一条龙
  - 采集（Python/Kafka）→ 实时或离线处理（Spark/Flink）→ 落数仓分层 → 简单可视化（Superset/Metabase 或 Plotly 图表）
  - 重点不是"大"，是**讲得清架构、踩过的坑、如何重跑、如何扩量**
- **简历**：项目经历按"背景 / 动作 / 结果 / 技术栈"写；GitHub 整理成能看的样子（README + 目录清晰）
- **面试准备**（同步进行）
  - SQL：窗口函数、行列转换、连续登录等经典题，每天 2–3 道
  - Python：装饰器、深浅拷贝、GIL、生成器
  - 大数据：HDFS/MapReduce/Spark 原理、shuffle、数据倾斜
  - 算法：数组/哈希/双指针/递归，刷 50 道左右
- **投递**：每周固定投 + 复盘面试问题，迭代简历

**月末自检**：能对着项目架构图，不卡壳地讲 20 分钟；完成过 1 次模拟面试。

## 4. 防弃坑（很重要）

1. **每天写代码**，哪怕只 30 分钟。手感靠频次不靠时长。
2. **卡住先自己搜 20 分钟**，再问人/问 AI——恢复的是你自己的肌肉记忆。
3. **每个练习都存 Git**，半年后这就是你的作品集。
4. **月末自检不过就延周**，不要带病前进（地基松后面全塌）。
5. **M4 是最容易劝退的月份**（环境+概念陡增），提前留好缓冲。
6. 加入一个打卡/社群，公开进度能显著提高完成率。

## 6. 就业市场分析（截至 2026 年 8 月）

> 以下数据来自公开招聘平台与行业报告整理（猎聘、智联、行业白皮书等），薪资为税前区间估算，会随城市/行业浮动。

### 6.1 市场总体：机会在，但初级岗内卷

- 2026 年大数据核心人才缺口预计 **180–230 万**，金融、制造、医疗等行业需求年增超 30%
- 但结构性变化明显：传统报表/清洗类岗位需求减少约 **40%**；"会点 SQL 和 Python"已不够，企业要的是"能独立搭管道、解决真实问题"的人
- 约 **60% 求职者停留在基础工具水平** → 这正是你用"落地项目"拉开差距的机会

### 6.2 技术栈信号：流批一体 + 云平台 + 数据治理

- Spark 仍是离线主力；**Flink（流批一体）薪资比同级 Spark 批处理高 30–50%**，差距还在拉大
- 2026 面试高频考点：实时数仓设计、湖仓一体（Iceberg/Hudi）、数据治理、至少会用一种云平台（EMR / DataWorks 类）
- **83% 的 JD 要求"精通 1–2 种工具 + 业务理解"**：简历写"熟悉 XX"无效，要写"用 XX 处理了 N 张表、耗时从 A 降到 B"
- 对路线图的调整：**M5 把 Flink 权重上调到与 Kafka 同级**；M4/M5 的项目全部带量化结果（数据量、耗时、优化前后对比）

### 6.3 薪资与地域（大数据开发岗，税前月薪）

| 经验 | 一线城市 | 新一线/强二线 | 三四线 |
|------|---------|--------------|--------|
| 入门（1-3年） | 10–18K（大厂/金融 20K+） | 8–12K | 5–8K |
| 中级（3-5年） | 25–50K | 18–30K | 20–30K |
| 高级/架构（5年+） | 40–100K+ | 35–50K | 35–50K |

- 岗位 **60%+ 集中在一线城市**；招聘旺季为 **3–5 月、9–11 月**（约占全年 70%）

### 6.4 学历现实与你的对策（全日制大专 + 自考本科）

- 约 80% 岗位要求本科（计算机/统计/数学相关），大厂偏爱统招 985/211，算法岗基本硕士起步 → **你选开发方向、避开算法内卷，路径正确**
- 你的学历组合定位：**全日制大专为第一学历、自考本科为加分项**。现实是：
  - 大厂校招/社招初筛普遍卡"统招本科"，不要在第一梯队耗时间
  - **中小企业、外包、传统行业数字化部门、初创公司**对"大专+自考本科+强项目"组合接受度明显更高（中小型科技公司约占招聘量 42%）
- 半年内同步做三件事补短板：
  1. **认证**：腾讯云（公司在深圳，本地认可度高）或阿里云的大数据相关认证，如"腾讯云大数据开发工程师"认证——简历初筛的硬通货
  2. **项目**：2–3 个端到端项目放 GitHub，README 写清架构+量化结果（这是你对抗学历劣势最有力的武器）
  3. **内推**：深圳大数据圈线下 meetup / 社区 / 前同事关系，内推可以绕过 HR 学历初筛
- 半年后的目标画像：深圳中小科技公司 / 制造业数字化部门 · 数据开发 / ETL / 数仓初级岗 · **10–15K**

### 6.5 你的时间优势：训练结束正好赶春招

- 现在 2026 年 8 月 → 训练 6 个月至 2027 年 2 月 → 2 月打磨简历与作品集 → **3–5 月招聘旺季集中投递**
- 兜底路径：若 6 个月后仍差火候，先入 **ETL / BI / 数据运维岗**（门槛更低）积累真实经验，1 年内再转数仓/开发——这是市场公认的稳妥路线，不算走弯路

### 6.6 深圳本地打法（你已在深圳，这是你的主场优势）

- **市场盘子**：广东大数据开发岗位缺口约 4 万+，需求增速居数字技术岗前三；深圳岗位占全省约 45%，互联网/通信巨头聚集，金融科技、跨境电商、智能制造是三大热门行业
- **机会在哪里**：
  - 大厂（腾讯、华为等）数据中台团队——学历门槛高，**作为远期目标**，不投入主力
  - **主力目标**：深圳 100–500 人科技公司（约 42% 招聘量，更看重全栈落地能力）、跨境电商公司（深圳产业带，数据/报表需求大）、制造业数字化部门（供应链数据团队）
  - **过渡跳板**：外包/驻场数据开发（对学历宽容，先入行积累真实数据量，1–2 年跳甲方）
- **深圳本地资源**：腾讯云开发者社区活动、云厂商 meetup、大数据技术沙龙（深圳每月都有），线下社交帮你拿内推；本地岗位可优先沟通，省去异地求职成本
- **薪资预期**：深圳初级数据开发 10–15K 是合理目标；外包起步可能 8–12K，别嫌低——先拿到真实生产环境的数据和项目，跳槽是深圳涨薪最快的方式
