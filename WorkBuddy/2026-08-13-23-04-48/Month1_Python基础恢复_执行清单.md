## 第 0 步：环境准备（已完成 ✔）

在终端（Mac 打开"终端"App）依次执行，确认环境：

```bash
python3 --version        # 应有 Python 3.x 输出
git --version            # 应有 git 版本输出
```

如果 `python3` 不存在：去 python.org 下载安装 3.12+，装完重开终端再试。
如果 `git` 不存在：先装 Xcode Command Line Tools（终端输入 `xcode-select --install` 跟随提示）。

然后：

1. **编辑器**：装 VSCode（code.visualstudio.com），装 Python 插件（商店搜 Python，装官方那个）
2. **GitHub**：注册账号（github.com），新建一个仓库，名字建议 `python-recovery`（公开）
3. **建本地目录**：

```bash
mkdir -p ~/dev/python-recovery/week1
cd ~/dev/python-recovery
git init
git branch -M main
git remote add origin https://github.com/<你的用户名>/python-recovery.git
```

4. **第一次提交**：新建 `README.md`（写一行"Python 恢复训练作品集"），然后：

```bash
git add README.md
git commit -m "init"
git push -u origin main
```

> 完成标准：GitHub 网页上能看到你的仓库和第一次提交。**这半年所有练习都提交到这里**。

## 第 1 周：语法地基（变量 → 流程控制 → 函数）

每天模式：**跟课 30–40 分钟（挑一个主线资料）→ 敲代码练习 40–60 分钟 → 记笔记 10 分钟**。
每天验收：当天练习全部跑通 + `git add/commit/push`。

| 天 | 学习内容 | 当天练习（全部要跑通） |
|----|---------|----------------------|
| D1 | 变量、数据类型、`print`、`input` | 问候程序：输入你的名字，打印"你好，xxx！" |
| D2 | 数字运算、类型转换、f-string | 温度转换：摄氏 ↔ 华氏；再算一下你的年龄的平方 |
| D3 | `if / elif / else`、比较运算 | 成绩分级：输入分数，输出 优/良/及格/不及格 |
| D4 | `for` 循环、`range`、字符串遍历 | ① 求 1–100 的和；② 打印九九乘法表 |
| D5 | `while`、`break` / `continue` | 猜数字：程序想一个 1–100 的数，你猜，直到猜对（给大了/小了提示） |
| D6 | 函数：定义、参数、返回值、默认值 | ① 把猜数字封装成 `guess_game()` 函数；② 写 `bmi(weight, height)` 返回 BMI 和判断 |
| D7 | **复盘日**：重跑本周全部代码，整理错题，`README.md` 写本周小结 | 把 D1–D6 各加一行注释说明它做了什么 |

**本周自检**：不查资料，写出一个 `count_evens(nums)` 函数（返回列表中偶数的个数）。写不出就 D7 加练半天。

## 第 4 周：10 个小练习冲刺（找回手感的高潮）

每天 1–2 个，全部独立完成、跑通、提交 Git。**完成标准写清楚了，照着自己验收。**

1. **命令行计算器**：支持 `+ - * /`，能连续计算（如输入 `1 + 2` 再输入 `+ 3`）
2. **待办清单**：命令行 `add/ list/ done/ delete` 四命令，退出后数据保留（存文件）
3. **词频统计**：读一个文本文件 → 统计每个词出现次数 → 输出出现最多的前 10 个
4. **猜数字（完整版）**：限 7 次机会，每次提示"大了/小了"，结束显示正确答案
5. **批量重命名**：把一个目录里的文件统一改名（如加日期前缀或序号）
6. **日志解析**：解析一段 access 日志文本，统计每个 IP 的出现次数，按次数排序输出
7. **斐波那契 / 质数**：两个函数 `fib(n)`、`is_prime(n)`，并写几个用例验证
8. **CSV 分组汇总**：读"部门,姓名,工资"的 CSV，按部门分组求和，写回新 CSV
9. **网页标题抓取**：用 `requests` 抓一个网页，用 `re` 或 `BeautifulSoup` 提取 `<title>`
10. **作品打包**：把 1–9 整理成一个 `projects/` 包，每个都有 `main()` 入口和一行说明

**月末自检（硬指标）**：不看任何资料，30 分钟内写出——"读 CSV → 按某列分组求和 → 写回新文件"。**写不出，第 4 周重来一周再进 M2。**
